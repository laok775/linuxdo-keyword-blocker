# Linux.do Keyword Blocker

一个轻量浏览器扩展，用关键词屏蔽 `https://linux.do/` 上不想看到的帖子。

## 功能

- 在扩展弹窗里添加、删除、清空关键词。
- 支持暂停/启用屏蔽。
- 支持两种匹配方式：包含关键词、完整词匹配。
- 支持两种处理方式：直接隐藏、淡化显示。
- 适配 Discourse 的前端路由和动态加载列表。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`E:\OPC\AI\linuxdo-keyword-blocker`
5. 打开 `https://linux.do/`，点击浏览器工具栏里的扩展图标添加关键词。

## 使用建议

- 如果只想屏蔽标题里出现的普通词，用“包含关键词”即可。
- 如果关键词很短，比如 `AI`、`Go`，可以切到“完整词匹配”，减少误伤。
- 不确定屏蔽规则是否过强时，先用“淡化显示”观察命中结果。

## 说明

关键词会保存在浏览器的 `chrome.storage.sync` 里。同一个浏览器账号开启同步后，设置通常会跟随浏览器同步。
