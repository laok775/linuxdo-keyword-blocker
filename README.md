# Linux.do Keyword Blocker

一个轻量浏览器扩展，用关键词屏蔽 `https://linux.do/` 上不想看到的帖子。

## 效果展示

扩展弹窗可以直接维护屏蔽词，并实时作用在 Linux.do 的帖子列表上。

### 暂停状态

关闭右上角开关后，扩展会暂停屏蔽，帖子列表保持原样展示。弹窗仍然可以继续添加、删除和调整关键词。

### 淡化显示

启用后选择“淡化显示”，命中关键词的帖子会被降低透明度，方便先观察规则是否误伤。适合刚开始整理关键词时使用。

### 直接隐藏

切换到“直接隐藏”后，命中关键词的帖子会从列表中移除，只保留未命中的内容。这个模式适合关键词规则已经比较稳定之后使用。

当前截图中的示例关键词包括：

- `注册`
- `接码`
- `pp`
- `PayPal`
- `gopay`
- `封号`
- `拉闸`

## 功能

- 在扩展弹窗里添加、删除、清空关键词。
- 支持暂停/启用屏蔽。
- 支持两种匹配方式：包含关键词、完整词匹配。
- 支持两种处理方式：直接隐藏、淡化显示。
- 适配 Discourse 的前端路由和动态加载列表。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页。
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
2. 打开“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`E:\OPC\AI\linuxdo-keyword-blocker`
5. 打开 `https://linux.do/`，点击浏览器工具栏里的扩展图标添加关键词。

## 使用建议

- 如果只想屏蔽标题里出现的普通词，用“包含关键词”即可。
- 如果关键词很短，比如 `AI`、`Go`，可以切到“完整词匹配”，减少误伤。
- 不确定屏蔽规则是否过强时，先用“淡化显示”观察命中结果。
- 规则稳定后再切换到“直接隐藏”，列表会更清爽。

## 说明

关键词会保存在浏览器的 `chrome.storage.sync` 里。同一个浏览器账号开启同步后，设置通常会跟随浏览器同步。
